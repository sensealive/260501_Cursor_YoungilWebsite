# 영일 웹사이트 프로젝트

## 개요
- 영일을 위한 정적 웹사이트 프로젝트입니다.
- 주요 페이지는 프로젝트 루트의 HTML 파일로 구성됩니다.
- 공용 에셋은 `assets/`에 위치합니다.

## 실행 방법
1. 의존성 설치:
   - `npm install`
2. 서버 실행:
   - `node server.js`

## 프로젝트 운영 메모
- 진행 현황은 `WORK_LOG.md`에 기록합니다.
- 작업 항목은 `TODO.md`에서 관리합니다.
- 이슈는 `BUGS.md`에 기록합니다.
- 아키텍처/운영 결정 사항은 `DECISIONS.md`에 남깁니다.
